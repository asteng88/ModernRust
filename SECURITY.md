# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in **ModernRust** (for example, related to SVG parsing/rendering or dependency vulnerabilities), please **do not** open a public issue.

Instead, report it privately using one of the following methods:
1. Open a private security advisory via the **Security** tab of the [ModernRust GitHub repository](https://github.com/asteng88/ModernRust/security/advisories/new).
2. Contact the maintainer directly via GitHub (`@asteng88`).

Please include:
- A clear description of the vulnerability and potential impact.
- Steps to reproduce or a minimal proof of concept.
- Affected version(s) and environment details.

We will acknowledge your report promptly and work with you to validate and address the issue before public disclosure.
